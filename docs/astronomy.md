# Ad Astra 天文知识

- 文档类型：天文知识说明，不涉及软件实现
- 文档版本：V1.0

- 精度定位：科普级。足够让画面中的星空与肉眼所见大致相符，不作为专业观测、导航或科研计算依据
- 配套文档：开发技术方案见 `docs/technical.md`

## 2. 产品里会出现哪些天文对象

用户看到的天空由几类对象组成：

| 对象 | 在天空中的含义 | 位置如何随时间变化 |
| --- | --- | --- |
| 恒星 | 极远处的发光天体，可视为固定在天球上的点 | 主要随地球自转东升西落；数十年到数百年尺度上还有自行 |
| 星座 | 人为把亮星连成的图案，用于辨认天空区域 | 随恒星一起做周日运动；连线本身不是物理结构 |
| 太阳 | 太阳系中心天体 | 每天东升西落，一年中沿黄道走完一圈 |
| 月亮 | 地球的天然卫星 | 每天相对恒星东移约 13°，约 29.5 天完成一次月相循环 |
| 行星 | 水星、金星、火星、木星、土星、天王星、海王星 | 相对恒星缓慢移动，有时逆行 |
| 黄道 | 太阳在一年中走过的视路径 | 相对恒星几乎固定，相对地平线随季节和地点变化 |
| 天赤道 | 地球赤道平面延伸到天球上的大圆 | 相对恒星几乎固定，相对地平线随地点变化 |
| 赤道网格 | 赤经、赤纬的参考线 | 随天球转动 |
| 地平网格 | 方位角、高度角的参考线 | 钉在当地地平上，不随恒星时转动 |
| 银河 | 银盘在天球上的光带 | 随恒星一起转动 |

首期不包含人造卫星、彗星、小行星和深空天体目录。

## 3. 天球：把无限远的天空当成一个球面

人眼无法分辨极远处天体的远近差别，只能看见它们在天空中的方向。因此可以把观察者放在球心，把所有天体投影到同一个单位球面上。这个球面叫做**天球**。

在天球上，只保留方向，不保留距离：

- 两颗星「靠近」，是指它们的方向夹角小，不一定物理上接近。
- 计算「某颗星在哪」，就是求它在天球上的方向，再换成观察者本地的方位和高度。

天球上有几个固定参考点：

- **北天极 / 南天极**：地球自转轴延伸到天球的两点。北天极附近目前靠近北极星。
- **天赤道**：与地球赤道共面的大圆，把天球分成北半天球和南半天球。
- **春分点**：天赤道与黄道的一个交点，是赤经的零点。
- **天顶**：观察者正上方。
- **天底**：观察者正下方。
- **地平圈**：天顶的正交大圆，也就是当地的地平线。

同一颗星在天球上的位置，对全世界几乎相同（忽略视差）；它在当地天空中的方位和高度，则完全取决于观察者站在地球的哪里、当地是什么时刻。

## 4. 观测者：地点决定「哪一片天空在头顶」

观测者由地球表面的位置描述：

- **纬度 φ**：北纬为正，南纬为负。决定北天极的高度：北天极的高度角约等于当地纬度。
- **经度 λ**：东经为正，西经为负。决定同一时刻各地的恒星时，也就是「天球已经转过了多少」。
- **海拔**：会影响地平线几何和大气折射。本产品按海平面处理，海拔缺省为 0。

几个直观后果：

- 赤道上，北极星贴着北方地平线；北极点上，北极星几乎在天顶，恒星绕天顶转圈，没有东升西落。
- 北半球看不到太靠近南天极的恒星；南半球看不到太靠近北天极的恒星。可整夜不落下的星叫做**拱极星**。
- 同一时刻，经度每差 15°，地方恒星时大约差 1 小时，星空「转动」约 15°。

观测地点和显示时钟用的时区是两件事。地点回答「站在哪里抬头」；时区只回答「钟面上写的几点对应宇宙中的哪一瞬间」。

## 5. 时间：从某地钟面时刻到天文计算时刻

这是「各地方时间的天体如何计算」的入口。天体位置不直接等于日历上的年月日，而等于宇宙中的一个绝对瞬间。地方民用时间必须先换成这个瞬间，才能继续算天空。

### 5.1 需要区分的几种时间

| 名称 | 谁在用 | 含义 |
| --- | --- | --- |
| 民用地方时 | 用户看到的日期和时间 | 某时区钟面上的时刻，含夏令时规则 |
| UTC | 现代民用世界时 | 协调世界时，是各地民用时间换算的公共枢纽 |
| UT1 | 地球自转 | 由地球实际自转定义的世界时 |
| TT | 太阳系动力学 | 地球时，均匀流逝，行星理论在这个尺度上积分 |
| 儒略日 | 天文计算内部 | 把日期时刻写成一个连续的天数 |

规则是：

1. 用户输入的永远是「某时区的民用地方时」。
2. 先换成 UTC，得到绝对瞬间。
3. 恒星的周日运动主要跟地球自转有关，用世界时即可。
4. 太阳、月亮、行星的轨道运动需要更均匀的 TT。
5. 画面上再把 UTC 格式化回用户选择的时区。

不能拿「本地 Date 的时、分、秒」直接当天文输入。同一串 `20:00`，在北京、伦敦、纽约对应完全不同的绝对瞬间。

### 5.2 时区、夏令时与「钟面时刻不存在」

民用地方时依赖 IANA 时区，例如 `Asia/Shanghai`、`Europe/London`、`America/New_York`、`Australia/Sydney`。时区规则包含：

- 标准偏移，如中国大陆全年 UTC+8。
- 夏令时，如纽约夏季 UTC−4、冬季 UTC−5。
- 历史上改过的边界和偏移。

两件必须单独处理的异常：

- **重复的地方时**：秋令时拨慢 1 小时，某个钟面时刻会对应两个 UTC 瞬间。需要明确取较早或较晚的那一个，不能 silently 猜。
- **不存在的地方时**：春令时拨快 1 小时，某个钟面时刻根本没有对应的 UTC。应拒绝这次输入，而不是自动挪到下一小时。

1970 年以前的历史时区数据并不完整；未来几十年的夏令时立法也无法预知。这些情况下，钟面时刻只能解释为「按现行规则前推或外推的近似民用时间」，不能当成当时真实颁布过的官方时刻。

观测地点和显示时区可以分开：人在东经 120° 的海上，钟面仍可选择显示 UTC 或某个城市时区。计算天空用的是经纬度和绝对瞬间，不是时区名字。

### 5.3 UTC、UT1 与地球时 TT

地球自转并不完全均匀，所以有三套相近但不相同的尺度：

- **UTC**：民用标准。通过闰秒尽量贴住 UT1。
- **UT1**：地球实际朝向。恒星时、春分点相对当地子午线的角度，本质上跟 UT1 走。
- **TT**：均匀原子时间尺度。太阳系天体的位置理论在 TT 上计算。

TT 与世界时之差记为 **ΔT**：

```text
TT ≈ UT + ΔT
```

ΔT 在 21 世纪初大约是 70 秒量级，并且缓慢变化。对肉眼星空：

- 70 秒造成的地球自转角约为 0.3 角分，远小于月亮圆面。
- 现行规则下 UT1 与 UTC 通常相差不到 1 秒，对应地球自转十几角秒。

因此科普展示可以近似 `UT1 ≈ UTC`，并用模型估算 ΔT，不必每次下载地球定向实测文件。这保证了「今晚抬头看到的位置」正确，但不保证角秒级测量。

超过已发表的闰秒表和地球自转预测之后，未来时刻只能使用外推模型；1826 年以前、UTC 建立以前的输入，应理解为历史模拟民用时刻，近似对应当时的世界时。

### 5.4 儒略日

天文计算几乎都把瞬间写成**儒略日**（Julian Day，JD）：从公元前 4713 年 1 月 1 日正午起算的连续天数，含小数。

Unix 毫秒与儒略日的关系是：

```text
JD = utcMillis / 86_400_000 + 2_440_587.5
```

其中 `2_440_587.5` 是 1970-01-01 00:00 UTC 的儒略日。J2000.0 标准历元是：

```text
J2000.0 = JD 2_451_545.0
        = 2000-01-01 12:00 TT
```

从 J2000.0 起算的天数：

```text
d = JD - 2_451_545.0
```

后续恒星时、岁差都可以用 `d` 展开。

### 5.5 从「某地某时」算到天空：总步骤

以「北京时间 2024 年 1 月 1 日 08:00，在北京抬头」为例。

1. **读入民用地方时**  
   时区 `Asia/Shanghai`，钟面 `2024-01-01 08:00`。中国大陆无夏令时，偏移固定 UTC+8。

2. **换成 UTC**  
   `2024-01-01 00:00:00 UTC`。

3. **写成儒略日**  
   得到对应的 `JD`，并由此得到 `d`。

4. **确定观测者**  
   北京约 39.9042°N，116.4074°E，海拔 0。

5. **算地方恒星时**  
   由世界时和经度得到当地春分点相对子午线转过的角度。见第 6.4 节。

6. **分别处理恒星和太阳系天体**  
   - 恒星：目录里的赤经赤纬（必要时自行传播）→ 日期赤道坐标 → 地平方位和高度。  
   - 太阳、月亮、行星：在 TT 上求相对于地球的方向 → 视赤经赤纬 → 同样转到地平坐标。月亮必须用站心位置。

7. **可选：靠近地平线时加上大气折射**  
   真实光线在大气中弯曲，天体看起来比几何位置更高一点。

8. **得到本地天空**  
   每颗天体都有方位角和高度角。高度角大于 0 表示在地平线以上。

同一钟面时刻若改到纽约，步骤 2 的 UTC 会不同，步骤 4 的经纬度也不同，后面全部结果都会变。同一 UTC 瞬间若改到悉尼，步骤 2 不变，但南半球的地平坐标会把许多北天星压到地平线以下。

### 5.6 一组具体对照

下列数值对应 `2024-01-01 00:00 UTC`、北京（约 39.90°N，116.41°E）。当时北京民用时间是早晨 8:00。

| 天体 | 方位角 | 高度角 | 直观含义 |
| --- | --- | --- | --- |
| 太阳 | 约 124° | 约 +3.3° | 刚升起不久，在东南方低空 |
| 月亮 | 约 258° | 约 +32° | 在西南方，中等高度 |
| 木星 | 约 4° | 约 −37° | 在北方地平线以下，当时看不见 |

方位角从正北起算、向东增加：90° 是东，180° 是南，270° 是西。高度角 0° 是地平线，90° 是天顶，负值在地下。

## 6. 坐标系

要把「目录里的位置」变成「抬头看到的位置」，需要经过几层坐标。

```text
恒星目录 / 行星理论
    → 赤道坐标（赤经、赤纬）
    → 日期赤道坐标（岁差、章动后的「今天的赤道」）
    → 地平坐标（方位角、高度角）
    → 观察者的视线方向
```

### 6.1 赤道坐标：赤经和赤纬

赤道坐标把天球当成地球仪的外延：

- **赤纬 δ（Declination）**：类似纬度，从天赤道量起，北正南负，范围 −90° 到 +90°。天赤道上 δ = 0°，北天极为 +90°。
- **赤经 α（Right Ascension）**：类似经度，从春分点向东量。习惯用时、分、秒，24 时 = 360°，因此 1 时 = 15°。

赤道坐标几乎不随观察者地点改变，所以星表都用它来出版。一颗星的赤经赤纬，在全世界的星图上是同一对数字。

把赤经赤纬写成天球上的单位方向（x 指向春分点，z 指向北天极）：

```text
x = cos(δ) * cos(α)
y = cos(δ) * sin(α)
z = sin(δ)
```

其中 α 先由时换成弧度：`α = 赤经时数 × 15°`。

### 6.2 历元、岁差和章动

地球自转轴在缓慢摆动：

- **岁差**：地轴大约 26,000 年绕一圈，春分点沿黄道西移。J2000 的赤经赤纬，到 2100 年会有大约 1.4° 的系统偏移。
- **章动**：地轴的较小周期性摆动，主要周期约 18.6 年，幅度大约 9 角秒量级。

因此必须说明「哪一天的赤道」。星表通常给出 **J2000 / ICRS** 坐标；计算某个日期的天空时，要把它们转到**日期赤道坐标**。对肉眼星空，岁差是百年尺度上必须考虑的项；章动对科普画面通常小于一个月亮直径的百分之一。

本产品的精度目标是亮星在当前年份前后 200 年内，角误差不超过约 5 角分。

### 6.3 地平坐标：方位角和高度角

地平坐标钉在观察者身上：

- **高度角 a（Altitude）**：从地平线向上量，0° 在地平，90° 在天顶，负值在地下。
- **方位角 A（Azimuth）**：从正北起算，向东增加。0° 北，90° 东，180° 南，270° 西。

对应的地平单位向量约定为：

```text
x = -cos(a) * sin(A)    西（渲染 +X）
y = sin(a)              天顶
z = cos(a) * cos(A)     北
```

反过来：

```text
a = arcsin(y)
A = atan2(-x, z)        再折算到 0°–360°
```

方位角仍是北为零、向东增加。渲染把东放到 `-X`：Three.js 相机朝向 `-Z` 时右侧为 `+X`，这样面朝南时左东右西，与肉眼一致。若写成 `x = cos(a) * sin(A)`（东），东西会左右镜像。

地平坐标随地球自转快速变化：恒星大约每 4 分钟在方位/高度上明显移动一点，一夜之间东升西落。

### 6.4 地方恒星时：连接赤道与地平

**恒星时**回答：春分点此刻在当地子午圈以东多远。

一个常用近似（从 J2000.0 展开，单位为恒星时小时）是：

```text
GMST ≈ 18.697374558 + 24.06570982441908 × d
LST  = (GMST + λ / 15)  mod 24
```

- `d` 是从 J2000.0 起算的世界时天数。
- `λ` 是东经，单位为度。除以 15 是因为 15° 经度对应 1 小时。
- **GMST** 是格林尼治平恒星时；**LST** 是地方平恒星时。

系数 `24.06570982441908` 大于 24，是因为地球在公转，太阳日比恒星日长约 4 分钟。恒星日约 23 小时 56 分，所以星空每天提前约 4 分钟升起。

有了 LST，一颗星的**时角** H 为：

```text
H = LST − α
```

时角是当地子午圈与这颗星之间的角距。H = 0 表示这颗星在正南（北半球）或正北（视具体半球和赤纬）的子午圈上，此时高度角最高。

### 6.5 赤道坐标转到地平坐标

经典球面三角公式：

```text
sin(a) = sin(φ) sin(δ) + cos(φ) cos(δ) cos(H)

sin(A) = −cos(δ) sin(H) / cos(a)
cos(A) = (sin(δ) − sin(φ) sin(a)) / (cos(φ) cos(a))
```

其中 φ 是纬度，δ 是赤纬，H 是时角，a 是高度角，A 是方位角。实际求方位角时用 `atan2`，避免象限错误。

等价地，可以把第 6.1 节的赤道单位向量乘上一个由 LST 和纬度决定的旋转，直接得到「东、天顶、北」分量。旋转只依赖时间和地点，不依赖某一颗星，所以同一瞬间所有恒星可以共用这一步。

### 6.6 黄道坐标

**黄道**是地球公转轨道平面延伸到天球上的大圆，也是太阳在一年中走过的视路径。

黄道与天赤道的交角叫做**黄赤交角 ε**。J2000 平黄赤交角约为：

```text
ε ≈ 23.439°
```

正是这个交角造成了四季：太阳赤纬在一年中大约于 −23.4° 与 +23.4° 之间变化，夏至靠近北回归线，冬至靠近南回归线。

黄道经度 λ（从春分点沿黄道量）与赤经赤纬的关系，在黄纬为 0 时为：

```text
tan(α) = sin(λ) cos(ε) / cos(λ)
sin(δ) = sin(ε) sin(λ)
```

太阳的几何黄纬接近 0，所以太阳几乎严格走在黄道上。月亮和行星有小的黄纬，会离开黄道一小段距离，但肉眼仍大致沿黄道一带运动，这一带叫做黄道带。

## 7. 恒星位置

### 7.1 星表给出什么

一颗恒星在目录中至少需要：

- 某一历元（通常 J2000）的赤经、赤纬
- 视星等，表示看起来有多亮
- 可选：自行、视差、色指数、专名、所属星座

恒星距离极远，在同一瞬间从地球各地看去，方向几乎相同，不必做站心视差改正。这与月亮相反。

### 7.2 自行

恒星并非绝对静止。它们相对太阳系有空间运动，投影到天球上就是**自行**：赤经、赤纬每年改变多少角秒。

对大多数肉眼可见恒星，一个世纪的自行只有角秒到一两角分。少数近距快星例外，例如巴纳德星。百年尺度上，把位置写成：

```text
p(t) = normalize( p0 + (dp/dt) × Δt )
```

其中 `p0` 是 J2000 的单位方向，`dp/dt` 是每年的方向变化，`Δt` 是距 J2000 的儒略年。这忽略了径向速度造成的透视加速，对科普足够；对已知极高自行的近星，才需要更完整的六维空间运动。

### 7.3 恒星的周日运动

对观察者来说，恒星最显著的运动不是自行，而是地球自转造成的**周日运动**：

- 天体从东方升起，在子午圈达到最高，从西方落下。
- 整个天空约 23 小时 56 分转一圈。
- 北纬 φ 处，赤纬大于 `90° − φ` 的星永不落下；赤纬小于 `φ − 90°` 的星永不升起。

季节变化来自太阳在黄道上的移动：某个星座在「傍晚刚黑」时出现在南天的日期，大约每月提前两小时，因此有「四季星空」的说法。

## 8. 太阳、月亮和行星的位置

恒星可以当作钉在天球上的点；太阳系天体必须按力学理论，对每一个绝对瞬间重新求方向。

### 8.1 计算在求什么

对某一瞬间，需要的是从观察者指向天体的单位方向，以及一些附加量：

- 地平方位角、高度角
- 赤道赤经、赤纬
- 视星等
- 月亮还需要相位；土星还需要光环相对视线的倾角

距离本身不直接画到天球上，但距离进入光行时、视差和视亮度。

### 8.2 行星理论概要

太阳系内天体的位置，由行星理论给出日心坐标，再转到地心或站心。科普级常用经过裁剪验证的经典理论（例如 VSOP87 行星理论，加上月球理论与坐标变换），目标是与实验室级星历相比大约 1 角分以内。

概念步骤：

1. 在 TT 上求地球和目标天体相对太阳的位置。
2. 相减得到天体相对地球的矢量。
3. 扣除光从天体走到地球的时间，再迭代一次（光行时）。行星距离数个天文单位时，光行时可达数十分钟。
4. 加上地球轨道运动造成的光行差，以及岁差、章动，得到视赤经赤纬。
5. 再转到当地地平坐标。

太阳就是「观察者看向太阳中心」的那个方向；它在黄道上的黄经大约每天增加 1°，一年回到春分点。

### 8.3 地心位置与站心位置

- **地心**：以地球中心为原点。对恒星和大多数行星足够。
- **站心**：以观察者所在地表为原点。

月亮离地球只有约 60 个地球半径，不同地点看到的月亮方向可差 1° 左右，这就是**月球视差**。计算月亮必须用站心位置，否则它会整体偏高或偏低，靠近地平线时尤其明显。太阳视差只有几角秒，行星更小，科普上通常可忽略，但完整算法仍可统一走站心路径。

### 8.4 行星的视运动规律

从地球上看，行星大致沿黄道移动，但速度和方向会变：

- **顺行**：相对恒星向东移动，这是常见状态。
- **逆行**：地内或地外行星在冲或内合前后，相对恒星暂时向西退。这是两个绕日轨道投影造成的视现象，不是行星真的折返。
- **合**：与太阳同一方向，淹没在晨光或暮光里。内行星有上合与下合。
- **冲**：地外行星与太阳黄经相差 180°，整夜可见，通常最亮。

水星和金星是地内行星，永远在太阳附近摆动，有最大距角；火星、木星、土星等可以在半夜出现在南天。天王星、海王星肉眼几乎不可见，产品中仍作为太阳系天体显示。

行星只应理解为天空中的光点。它们的真实角直径极小，科普画面不会按真实盘面大小来画。

### 8.5 月亮的运转

月亮绕地球约 27.3 天相对恒星一周（恒星月），约 29.53 天相对太阳一周（朔望月）。后者决定月相。

因为月亮轨道相对黄道倾斜约 5°，它多数时候在黄道附近，只有在交点附近才可能发生日食或月食。月亮每天相对恒星东移约 13°，所以「月亮升起」每天大约推迟 50 分钟。

## 9. 大气折射

真空中的几何高度角，并不是眼睛看到的高度角。光线进入大气后向下弯曲，天体看起来比实际更高：

- 天顶附近折射接近 0。
- 地平线附近标准大气下可达约 34 角分，差不多一个太阳或月亮的直径。
- 所以几何上还在地平线以下一点的太阳，肉眼已经能看见「日出」。

标准折射模型假设海平面、典型温度和气压。真实天气、地形和海拔都会改变结果。地平线以下很深的对象，不应被折射「抬」到可见区域。

产品中的太阳、月亮、行星使用标准温压下的折射；地平线附近的实际位置仍可能受当地天气影响。这项改正不纳入与实验室星历对比的严格误差预算。

## 10. 黄道、天赤道和坐标网格

这些辅助线不对应实体，而是帮助理解天空如何被坐标切开。

### 10.1 天赤道

在日期赤道坐标系中，所有赤纬为 0 的点连成一个大圆，就是天赤道。转到地平坐标后：

- 它与地平线的交点大致在正东和正西附近（忽略折射）。
- 它在南天或北天升起的最高高度，等于 `90° − |φ|`。

### 10.2 黄道

根据当时的黄赤交角，在天球上画出黄纬为 0 的大圆。太阳永远贴近这条线；月亮和行星在其两侧不远。黄道的两极（黄北极、黄南极）在黄纬 ±90°，J2000 约在赤经 18h / 6h、赤纬 ±(90° − ε)。黄道相对地平线的倾角随季节和观测纬度变化，所以「黄昏后黄道竖起来」或「躺在地平线上」会随日期明显不同。

### 10.3 赤道网格与地平网格

- **赤经 / 赤纬网格**：画在天球上，随恒星时转动。缩小视野时可以把间隔从几十度加密到几度。
- **方位 / 高度网格**：画在当地地平上，不随恒星转。它只随观察地点和「朝哪看」变化。

两类网格回答不同问题：赤道网格适合对照星图；地平网格适合回答「那颗星在东偏南多少、仰角多少」。

大圆在平面上应沿球面细分，否则长弦会「穿进」天球内部，看起来像直线抄近路。

## 11. 星座

国际天文学联合会认定 **88 个星座**。正式定义的是它们在天球上的**边界**，用来唯一判定「这颗星属于哪个星座」，并不是人们熟悉的内部连线。

连线是文化与教学约定：猎户座的「沙漏」、北斗七星都属于连线传统，不同星图可以画得不一样。本产品使用自有的连线定义，每条线段连接两颗恒星；星座名称的位置取该星座所用恒星方向的平均，再归一化到天球上，因此名称会随星空一起转动，而不是钉在屏幕某一像素。

星座形状在几十年内几乎不变。真正改变星座「今晚在哪」的，是地球自转和公转，不是连线本身。

## 12. 视星等、颜色和可见度

**视星等**度量天体看起来有多亮。数值越小越亮：

- 太阳约 −27
- 满月约 −13
- 金星最亮时约 −4.5
- 天狼星约 −1.5
- 织女星大约 0
- 肉眼在良好暗夜大约可以看到 +6 到 +6.5
- `+8` 已经暗于多数城市肉眼极限，需要较暗的天空或光学辅助

相邻 1 等，亮度相差约 2.512 倍；5 等相差 100 倍。产品用视星等上限筛选恒星：上限 5.5 表示只画出不暗于 +5.5 的星。太阳、月亮、行星不参与这道筛选。

恒星颜色来自表面温度，观测上常用 B−V 色指数：偏蓝的热星、偏红的冷星。缺失色指数时，按中性白处理即可。

白昼时大气散射会淹没暗星。太阳高度角越高，只有更亮的天体还留在视觉上。这是光学可见度，不是天体「白天不存在」。

## 13. 月相

月相取决于太阳、月亮、地球的相对位置，也就是月亮被太阳照亮的那一面朝向地球多少。

一个朔望月里，月亮相对太阳的黄经差从 0° 走到 360°：

| 黄经差 | 名称 | 形态 |
| --- | --- | --- |
| 0° | 新月 | 几乎看不见，与太阳同升同落 |
| 45° | 娥眉月 | 细弯，傍晚西天 |
| 90° | 上弦月 | 右半亮（北半球常见观感），傍晚在南天 |
| 135° | 盈凸月 | 大部分被照亮 |
| 180° | 满月 | 整夜可见，太阳落下时升起 |
| 225° | 亏凸月 | 开始亏缺 |
| 270° | 下弦月 | 左半亮，后半夜到清晨 |
| 315° | 残月 | 细弯，黎明东天 |

照明比例并不是黄经差的简单折半，因为还取决于月亮轨道倾角和观察几何；对科普展示，用相位角或被照亮比例已经足够。南北半球看到的月面会上下颠倒，但盈亏的物理定义不变。

## 14. 昼夜与曙暮光

天空亮暗不取决于钟面几点，而取决于**太阳的高度角**。常用分界：

| 太阳高度角 | 阶段 | 含义 |
| --- | --- | --- |
| ≥ 0° | 白昼 | 太阳在地平线上 |
| 0° 到 −6° | 民用曙暮光 | 户外活动仍可不用人工照明 |
| −6° 到 −12° | 航海曙暮光 | 海天线可辨，亮星出现 |
| −12° 到 −18° | 天文曙暮光 | 天空仍未完全暗到天文观测极限 |
| < −18° | 夜晚 | 太阳散射可忽略 |

这些边界是连续过渡，不是开关。极地夏季可能出现极昼：太阳高度角整天为正；冬季可能出现极夜：太阳整天在 −18° 以下或以下某档。这完全由纬度和太阳赤纬共同决定，不需要单独的「极地模式」物理。

日出日落的钟面时刻随经纬度和日期变化：春分秋分全球昼夜大致等长；北半球夏至白昼最长。这正是第 6.6 节黄赤交角的直接结果。

## 15. 运转规律总览

把前面的运动叠在一起，就是用户拖动时间时看到的全部变化。

### 15.1 以小时计：地球自转

主导现象是整个天空绕天极转动。恒星、星座、黄道、天赤道一起转；地平线和方位网格不动。太阳、月亮、行星也跟着转，但相对恒星还有自身的慢漂移。

播放「一夜」时，应看到东升西落，而不是天体在星座之间乱跳。

### 15.2 以日到月计：太阳和月亮相对恒星移动

- 太阳每天沿黄道东移约 1°，约 365.24 日回到春分点。这造成季节和「同一地方时看到的星座」变化。
- 月亮每天东移约 13°，约 29.5 日完成月相。同一时刻连续看若干天，月亮会在黄道带上明显换位置。

### 15.3 以月到年计：行星视运动

行星相对黄道带缓缓移动，偶有逆行。木星约 12 年绕黄道一周，土星约 29 年。按「年」或「十年」跳转时，背景恒星几乎没动（除周日相位），行星会换星座。

### 15.4 以十年到百年计：自行与岁差

亮星图案大体依旧，但：

- 高自行近星会相对邻星挪动，星座连线会缓慢变形。
- 岁差让春分点移动，赤道坐标的数字改变；北极附近「北极星」在更长尺度上也会换星星。

产品覆盖当前年份前后约 200 年。在这个窗口里，周日运动和行星运动是主角，自行是配角。

### 15.5 地点变化：同一瞬间的不同天空

保持绝对时间不变，只换地点：

- 改纬度：北天极高度改变，可见星座集合改变，南北半球的「南」对应的星空完全不同。
- 改经度：相当于换了一个恒星时，星空绕天极转过相应角度。东边的地点看到更「晚」的那一幕星空。
- 改半球：方位习惯仍然是北为零向东增加，但许多熟悉的北天星座会落到地平线下，月面看起来也会倒转。

保持钟面时刻不变、改时区或改城市，则先要换算成不同的 UTC，再走完整条计算链。这与「同一 UTC、不同地点」不是同一件事。

## 16. 精度边界

以下是本产品采用的天文精度立场，而不是软件指标：

- 太阳和主要行星：与高精度星历相比，角误差目标不超过约 3 角分。
- 月亮：不超过约 5 角分。月球视差必须计入。
- 亮星：当前年份前后 200 年内，不超过约 5 角分。
- 黄道、天赤道在视觉上应与坐标定义一致。
- 地平线附近的大气折射使用标准模型，不声称包含当地气象改正。
- 不宣称角秒级、不用于望远镜指向、航海或计时。

角分是肉眼极限附近的尺度：满月直径约 30 角分。3 到 5 角分的误差，在全天画面上几乎看不出来，但已经远宽于专业星历。

## 17. 术语表

- **天球**：以观察者为心、表示方向的假想球面。
- **天顶 / 地平线**：当地正上方，以及天空与地面的界线。
- **赤经 / 赤纬**：天球赤道坐标系，类似经纬度。
- **方位角 / 高度角**：当地地平坐标系。
- **春分点**：赤经零点，天赤道与黄道的一个交点。
- **黄道 / 黄赤交角**：太阳视路径，以及它与天赤道的交角，约 23.4°。
- **地方恒星时**：春分点相对当地子午圈的时角。
- **时角**：天体相对当地子午圈的角距。
- **儒略日**：连续计数的天文日期。
- **UTC / UT1 / TT**：民用世界时、地球自转时、均匀地球时。
- **ΔT**：TT 与世界时之差。
- **岁差 / 章动**：地轴的长期进动与周期摆动。
- **自行**：恒星在天球上的缓慢位移。
- **地心 / 站心**：以地心或以地表观测者为原点。
- **视差**：因观测者位置不同造成的方向差，月亮最显著。
- **光行时**：光线从天体传到地球所用的时间。
- **视星等**：看起来有多亮，越小越亮。
- **朔望月**：月相循环周期，约 29.53 日。
- **拱极星**：某纬度永不落下的星。
- **冲 / 合 / 逆行**：行星相对太阳或相对恒星的特征视位置与视运动。
- **民用 / 航海 / 天文曙暮光**：由太阳高度角 −6°、−12°、−18° 划分的晨昏阶段。
- **历元**：坐标所对应的参考时刻，常用 J2000.0。
